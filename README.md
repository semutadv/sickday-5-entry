A sick-day excuse in one line, written for the make.fun bounty "The
Funniest Sick-Day Excuse": the caller and their couch are in couples
therapy, and the work on their attachment issues cannot be interrupted
at this delicate stage. HR is encouraged to file it under wellness.

## Running it

`node main.ts` clears the output directory's contents and writes the
excuse to `/output/entry.txt` as plain UTF-8 text.
